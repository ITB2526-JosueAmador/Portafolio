## Sobre mí

Me apasiona la intersección entre **música**, **tecnología** y **experiencias interactivas**.  
Creo herramientas, sonidos, interfaces y mundos digitales que combinan código, diseño y creatividad.

Áreas principales:

- Desarrollo web interactivo (HTML/CSS/JS, Three.js, React, etc.)
- Experimentación con MIDI, visualización de datos sonoros y arte generativo

## Proyectos Destacados

### 🎹 Aproximación al funcionamiento de las estaciones digitales de audio (DAW)

Exploración interactiva del mundo de las **Digital Audio Workstations** con un enfoque educativo y práctico.

**Características principales:**
- Sintetizador FM interactivo en el navegador (Tone.js)
- Teclado virtual + soporte para teclado físico (mapeo QWERTY)
- Reproductor de archivos MIDI con visualización de progreso
- Controles en tiempo real: harmonicity, modulation index, ADSR envelope
- Interfaz moderna con gradientes y animaciones suaves

**Tecnologías:**  
JavaScript · Tone.js · @tonejs/midi · HTML5 Audio · CSS Grid + Flexbox

→ [Ver proyecto en vivo](https://josueamador.com/proyectos/daw-exploration)  
→ [Código fuente](./proyectos/daw-synth)

### 🌌 Low-Poly Space Adventure – Modelado 3D & Videojuego

Videojuego corto en primera persona + entorno 3D low-poly con estética sci-fi minimalista.

**Características principales:**
- Escena principal: estación espacial abandonada con nebulosa de fondo
- Modelado, texturizado y rigging 100% hecho en Blender
- Iluminación volumétrica y partículas (polvo cósmico, chispas)
- Mecánicas básicas: caminar, interactuar con terminales, recoger logs
- Sistema de sonido ambiental procedural + música generativa suave
- Exportado y optimizado para web (Three.js) y escritorio (Unity)

**Tecnologías:**  
Blender · Unity / Godot · Three.js (versión web) · Substance Painter · Fmod / FMOD Studio (sonido)

→ [Jugar la demo web](https://itb2526-josueamador.github.io/Portafolio/html/shooter.html)
